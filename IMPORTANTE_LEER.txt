En computadoras propias
- Crear desde 0 la base de datos con el nombre "hospital_regional"
- Tener el proyecto abierto en VS
- Entrar a la terminal
- Ejecutar: composer install
- Ejecutar: cp .env.example .env
- Cambiar el puerto en .env al que se muestra en XAAMP
- Ejecutar: php artisan key:generate
- Ejecutar: php artisan migrate:fresh --seed
- Ejecutar: php artisan serve
